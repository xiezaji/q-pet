# Q Pet · 网页版

把喜欢的角色放到浏览器里的桌宠，当前版本 2.1.0。在线试玩：<https://xiezaji.github.io/q-pet/>

纯静态站点，无构建、无后端、无第三方依赖。打开 `index.html` 即可运行，
所有设置和统计只存在当前浏览器的 localStorage / IndexedDB 里。

## 目录

| 路径 | 作用 |
|---|---|
| `index.html` | 桌面、任务栏、图层容器 |
| `css/app.css` | 全部样式，主题色通过 CSS 变量实时切换 |
| `js/pet.js` | 桌宠本体：状态机、拖动、气泡、点击台词 |
| `js/frames.js` | 从立绘实时生成四类动画帧（待机 / 按键 / 点击 / 拖动） |
| `js/bubble.js` | 气泡外框、文字排版、滚动、命中检测 |
| `js/settings.js` | 设置窗口外壳：标题栏、枢纽、分页、未保存提示 |
| `js/pages.js` | 八个设置页：气泡、通用、形象、动画、语音、导入、关于 |
| `js/pagestats.js` | 使用统计：键位热力图、角色陪伴、软件用时 |
| `js/store.js` | 配置、角色包、自定义动画、外框的读写 |
| `js/audio.js` | 单例 `<audio>` 播放台词与音效 |
| `js/stats.js` | 前台计时、按键计数 |
| `assets/chars/` | 四套内置角色包：立绘 WebP + 语音 MP3 + 清单 JSON |
| `tools/convert.py` | 把桌面版角色包转成网页资源 |

## 本地预览

```bash
python web/_serve.py 8780
# 打开 http://127.0.0.1:8780/
```

`file://` 直接双击也能跑，只是浏览器会限制部分资源加载，建议起个本地服务。

## 和桌面版的差别

透明窗口、点击穿透到桌面、开机自启动、系统级按键统计这些浏览器做不到。
网页版换成页面内的可拖拽舞台、页内按键计数，其余交互与桌面版一致：
四类动画、气泡样式、语音台词（可编辑 / 删除 / 导入）、换角色、导入角色包、使用统计。

## 部署

仓库根目录的 `.github/workflows/pages.yml` 会把 `web/` 发布到 GitHub Pages，
推送到 `main` 即自动上线。
